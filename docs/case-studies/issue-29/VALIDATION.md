## Notices and practical limits

- The existing 1,354-line registry collector emits the repository's warning threshold above 1,350; it remains below the enforced 1,500-line limit. The change adds no oversized source file.
- Vite reports existing extensionless imports in settings schemas as incompatible with a future native configuration loader. The current configured build succeeds. These notices are not suppressed.
- JSDOM reports that canvas `getContext` is unavailable during component tests. Native rendering, painted geometry, exported images and clipboard behavior are checked in real browsers; the unit tests do not claim to validate GPU rendering.
- Linux WebKit is adequate for the new geometry/controls checks. The issue-23 backdrop compositor acceptance still runs on native macOS WebKit in CI, because its Linux GTK screen renderer differs. That check is not removed or relaxed.
- The solver remains a bounded experimental heuristic. It preserves already satisfied manual input, constraints and self-closed halves; it does not promise a globally optimal layout for every graph. The README reports the actual non-identical nearest painted distances rather than claiming universal exact equality.
- Existing external feed/archive availability limits are retained and listed in the inherited inventory. No new upstream defect was identified in this investigation.
